To use this project, you need to have the following requirements :
1. Download the Llama 3.5 model from the Ollama website (Detailed guide on this can be found on youtube)
2. Install the packages referenced in the python code
3. Download Node.js
4. Download ngrok to deploy the website (Optional)

Procedures:
1. Run the python file (A flask server will be created)
2. Open up terminal and go to the directory where the node.js file is present and use npm index.js to run the node.js file
3. copy the server link generated by the terminal and add "/response.html" in your browser tab
4. (Optional) If you have downloaded ngrok you can open up terminal and run the following command "ngrok http 3000" to deploy the website (Make sure to add "/response.html" to the website link)
